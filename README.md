# Utash
Пять оригинальных RGBA-планов Rural Evening v2, 2560 × 1440, и Atmosphere Engine 0.4.0 из переданного пакета. Исходные PNG сохранены без изменений. Three.js 0.181.1 поставляется локально; сборка и CDN не нужны.

Запуск: `python -m http.server 4185` из папки проекта, затем http://localhost:4185. Для публикации GitHub Pages: ветка main, корень репозитория.

Вечерний свет уже нарисован в изображениях. Время суток меняет процедурную атмосферу и стилизованную тонировку, а не физическое освещение объектов. Пресет «Исходная сцена» отключает погоду и тонировку. Динамические тени не включены: для них нужны подготовленные принимающие маски и высоты объектов.

Планы: небо 0, лес 10, дома 20, растительность 30, поле 40. Облака 5/15, туман 35, дождь 60. Полное разрешение рендера сохраняется; CSS вписывает холст в экран с nearest sampling. Городские эффекты отключены.
